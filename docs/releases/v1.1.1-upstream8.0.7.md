# v1.1.1-upstream8.0.7 - 2026-10-01

## Summary

- Documentation-only release. It ships the same binaries as
  `v1.1.0-upstream8.0.7` and adds no code, configuration or dependency
  change.
- Records the standing decision that `codex/codex-tool-search-shim` is a
  permanent read-only archive branch that is never merged into `main` and is
  never built on.
- No configuration migration is required, and no compatibility impact is
  expected.

## Upstream alignment

- Upstream release: `v8.0.7`
- Previous baseline: `v8.0.7`
- Intake record: [absorbed.md](../../ops/upstream-intake/absorbed.md)
- Ported: none. This release ports no new upstream work. It is built directly
  on the `v8.0.7` baseline that `v1.1.0-upstream8.0.7` established, and it
  keeps that release's `-upstream8.0.7` suffix because it is still built on
  the same baseline. The only commit since `v1.1.0-upstream8.0.7` is
  `9ce07aef`, which changes `AGENTS.md` only.
- Skipped: none. No upstream commit was assessed or excluded for this
  release.

## Changed

- `AGENTS.md` now states that `codex/codex-tool-search-shim` is never merged
  into `main` and must not be built on, and that the tool-search capability it
  explored shipped through the responses-tools pipeline instead. The previous
  wording kept the branch only "while it holds work worth recovering", which
  left room to merge it later.

## Validation

- `ops/upstream-intake/verify-absorb.sh` was run on this release candidate
  with `GOTOOLCHAIN=go1.26.4`, the version both CI workflows pin, so the
  `gofmt` stage matches CI. It covers the maintenance tooling tests, `gofmt`
  over tracked sources, `go vet ./...`, the Responses-tools package tests, the
  full `go test ./... -count=1` suite, `-race` runs of the
  concurrency-sensitive packages, and a server build.
- **Client replay coverage: not performed, and not applicable.** This release
  changes no runtime code, so no Codex, Gemini, Vertex or AI Studio client
  turn was replayed against it. The gate result covers the automated checks
  only.
- Cross-platform behavior is covered only by the release workflow's asset
  build and checksum verification; no artifact was exercised on a non-macOS
  platform. The binaries are byte-for-byte equivalent in source terms to
  `v1.1.0-upstream8.0.7`.
