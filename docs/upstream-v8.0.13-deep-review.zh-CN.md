对首次评估中暂缓的 18 个提交逐项复核后，追加吸收 **11 个提交的实质改动**，另移植 **1 个提交的验收测试**。其余 6 项分别是 3 个合并包装、1 个宣传性 README 更新、2 个已由 fork 现有实现满足的修复。

## 配置与调用方影响

- 多代理设置规范路径为 `client.codex.optimize-multi-agent-v2`。旧 `oauth.providers.codex.*`、`providers.codex.*` 和 `codex.*` 路径可读取；规范叶子字段按“是否存在”优先，包括显式 `false` 和 `null`。旧 SDK 的 `CodexOptimizeMultiAgentV2` 与 `Codex.OptimizeMultiAgentV2` 仍可用于程序化配置，快照和保存投影为规范路径。
- Codex、Claude、xAI 共享提供商设置迁入 `upstream.*`。这些设置同时作用于 OAuth 和 API key；OAuth 专用 Codex 头等仍留在 OAuth 作用域。历史配置无需先手工改写即可加载，成功保存时采用对应的规范布局。
- 当前自定义工具桥接仍由已有路由策略决定。本次没有新增 `client.codex.enable-apply-patch`，也没有替所有提供商自动声明 freeform 能力；通用 function 路由的补丁说明和输入保真得到修复，原生 Codex 模板能力得到保留。
- 没有新增依赖、修改 module path、重新引入上游工作流或修改永久等待门禁。没有执行发版、Homebrew 更新、配置部署或服务重启。
