**步骤 3：写最小实现**

`event:` 前缀 → `RememberUpstreamResponseEventType`，不抽模型。`data:` / `data: ` 前缀剥掉后当 JSON。无族绑定时按 spec 嗅探一族。OpenAI：`response.model` 然后 `model`；terminal = JSON `type` 或 LastEvent 属于 completed/done/failed/incomplete/cancelled/canceled。Claude：`message.model` 然后 `model`，terminal=false。Gemini：三条 modelVersion 路径，terminal=true。候选存在后 `gjson.ValidBytes` 失败则丢弃。未绑定且无法嗅探时按 OpenAI。
