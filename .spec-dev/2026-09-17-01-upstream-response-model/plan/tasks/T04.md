### 任务 4：原文入口在日志门控前观测

**文件**：
- 修改：`internal/runtime/executor/helps/logging_helpers.go`（`AppendAPIResponseChunk`、`AppendAPIWebsocketResponse`）
- 修改：`internal/runtime/executor/helps/websocket_observer_helpers.go`（`EmitWebSocketResponseEvent`）
- 测试：`internal/runtime/executor/helps/logging_helpers_test.go`（及必要时新建短测）

**接口**：
- 消费：`ObserveUpstreamResponseBytes(ctx, payload []byte)`
- 产出：HTTP/WS 原文到达即观测，即使 request-log 关闭或 CommercialMode
- 覆盖 Scenario：关闭 request-log 仍观测、观测不改写出站字节
- 来源：spec Requirement「Observe independently of request logging」「Observation does not alter forwarded responses」

**步骤 1：写失败测试**

```go
func TestAppendAPIResponseChunkObservesWhenRequestLogDisabled(t *testing.T) {
	ctx := usage.BeginUpstreamResponseModelObservation(context.Background())
	usage.BindUpstreamResponseModelFamily(ctx, usage.FamilyOpenAI)
	cfg := &config.Config{RequestLog: false}
	chunk := []byte(`{"model":"gpt-5.4"}`)
	before := string(chunk)
	AppendAPIResponseChunk(ctx, cfg, chunk)
	if string(chunk) != before {
		t.Fatalf("chunk mutated")
	}
	if got := usage.UpstreamResponseModelFromContext(ctx); got != "gpt-5.4" {
		t.Fatalf("got %q, want gpt-5.4", got)
	}
}

func TestAppendAPIResponseChunkObservesInCommercialMode(t *testing.T) {
	ctx := usage.BeginUpstreamResponseModelObservation(context.Background())
	usage.BindUpstreamResponseModelFamily(ctx, usage.FamilyOpenAI)
	cfg := &config.Config{RequestLog: true, CommercialMode: true}
	AppendAPIResponseChunk(ctx, cfg, []byte(`{"response":{"model":"kept"}}`))
	if got := usage.UpstreamResponseModelFromContext(ctx); got != "kept" {
		t.Fatalf("got %q, want kept", got)
	}
}
```

再加 `AppendAPIWebsocketResponse` 与 `EmitWebSocketResponseEvent` 各一例：`RequestLog: false`，payload `{"model":"ws-model"}`，断言 FromContext 为 `ws-model` 且 payload 未改。读现有 `logging_helpers_test.go` 的 cfg 构造，复用 helper，不要另起 gin 上下文。

**步骤 2：运行测试确认失败**

运行：`go test ./internal/runtime/executor/helps/ -run 'TestAppendAPIResponseChunkObservesWhenRequestLogDisabled|TestAppendAPIResponseChunkObservesInCommercialMode' -count=1`

预期：观测值为空（函数在门控处直接 return）。

**步骤 3：写最小实现**

`AppendAPIResponseChunk` 与 `AppendAPIWebsocketResponse` **第一行**（nil 检查之后）：`ObserveUpstreamResponseBytes(ctx, chunk)`，再进入 `requestLogCaptureEnabled`。`EmitWebSocketResponseEvent` 在 `len(payload)==0` 之后同样调用，不改 payload。空 chunk 可不观测。

旧：

```go
func AppendAPIResponseChunk(ctx context.Context, cfg *config.Config, chunk []byte) {
	if !requestLogCaptureEnabled(cfg) {
		return
	}
```

新：先 `ObserveUpstreamResponseBytes(ctx, chunk)`，再门控。

**步骤 4：运行测试确认通过**

运行：同步骤 2 以及 `go test ./internal/runtime/executor/helps/ -count=1`。预期：PASS。`gofmt -w` 后 `go build -o test-output ./cmd/server && rm test-output`
