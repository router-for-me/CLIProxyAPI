**步骤 1：写失败测试**

在 `usage_helpers_test.go` 追加：

```go
func TestUsageReporterBuildRecordCopiesObservedModel(t *testing.T) {
	ctx := usage.BeginUpstreamResponseModelObservation(context.Background())
	usage.ObserveUpstreamResponseModel(ctx, "gpt-5.4", true)
	reporter := NewUsageReporter(ctx, "openai", "mapped-model", nil)
	record := reporter.buildRecord(usage.Detail{TotalTokens: 1}, false)
	if record.UpstreamResponseModel != "gpt-5.4" {
		t.Fatalf("got %q, want gpt-5.4", record.UpstreamResponseModel)
	}
}

func TestUsageReporterPublishFailureKeepsObservedModel(t *testing.T) {
	ctx := usage.BeginUpstreamResponseModelObservation(context.Background())
	usage.ObserveUpstreamResponseModel(ctx, "err-model", true)
	reporter := NewUsageReporter(ctx, "openai", "mapped-model", nil)
	record := reporter.buildRecord(usage.Detail{}, true, usage.Failure{StatusCode: 500})
	if record.UpstreamResponseModel != "err-model" {
		t.Fatalf("got %q, want err-model", record.UpstreamResponseModel)
	}
}

func TestNewUsageReporterBindsClaudeFamily(t *testing.T) {
	ctx := usage.BeginUpstreamResponseModelObservation(context.Background())
	_ = NewUsageReporter(ctx, "claude", "claude-sonnet-4-6", nil)
	ObserveUpstreamResponseBytes(ctx, []byte(`{"message":{"model":"claude-first"}}`))
	ObserveUpstreamResponseBytes(ctx, []byte(`{"model":"claude-later"}`))
	if got := usage.UpstreamResponseModelFromContext(ctx); got != "claude-first" {
		t.Fatalf("got %q, want claude-first", got)
	}
}

func TestUsageReporterBuildRecordEmptyWithoutObservation(t *testing.T) {
	ctx := usage.BeginUpstreamResponseModelObservation(context.Background())
	reporter := NewUsageReporter(ctx, "openai", "mapped-model", nil)
	record := reporter.buildRecord(usage.Detail{TotalTokens: 1}, false)
	if record.UpstreamResponseModel != "" {
		t.Fatalf("got %q, want empty", record.UpstreamResponseModel)
	}
}
```

T03 执行时 T02 已合入；本例证明 `NewUsageReporter` 绑定 Claude 族，而不是只测 Map。

**步骤 2：运行测试确认失败**

运行：`go test ./internal/runtime/executor/helps/ -run 'TestUsageReporterBuildRecordCopiesObservedModel|TestUsageReporterPublishFailureKeepsObservedModel|TestNewUsageReporterBindsClaudeFamily|TestUsageReporterBuildRecordEmptyWithoutObservation' -count=1`

预期：`UpstreamResponseModel` 为空字符串，AssertionError。

**步骤 3：写最小实现**

`newUpstreamAttemptContext`：`ctx = coreusage.BeginUpstreamResponseModelObservation(ctx)`（auth 包已 import `coreusage`）。

`NewUsageReporter` 在填完 provider/executorType 后：`usage.BindUpstreamResponseModelFamily(ctx, usage.MapExecutorToExtractionFamily(provider, reporter.executorType))`。注意 `NewUsageReporter` 里 executorType 可能仍空，`NewExecutorUsageReporter` 设完类型后再 Bind 一次。

`buildRecordForModel` 增加：`UpstreamResponseModel: usage.UpstreamResponseModelFromContext(...)`。`buildRecordForModel` 无 ctx → 把 ctx 存进 `UsageReporter`（`NewUsageReporter` 已有 ctx 参数，新增字段 `ctx context.Context`）。Home 401 不经 reporter、无 Begin 则字段空。
