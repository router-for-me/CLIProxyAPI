### 任务 5：Redis 用量队列写出字段

**文件**：
- 修改：`internal/redisqueue/plugin.go`（`queuedUsageDetail` 与 `HandleUsage` marshal）
- 测试：`internal/redisqueue/plugin_test.go`

**接口**：
- 消费：`Record.UpstreamResponseModel string`
- 产出：入队 JSON 非空时含 `upstream_response_model`，空则省略该键
- 覆盖 Scenario：队列写出观测值
- 来源：spec Requirement「Emit the observed model on the usage queue」

**步骤 1：写失败测试**

在 `TestUsageQueuePluginPayloadIncludesStableFieldsAndSuccess` 的 Record 增加 `UpstreamResponseModel: "claude-sonnet-4-6"`，断言：

```go
requireStringField(t, payload, "upstream_response_model", "claude-sonnet-4-6")
```

另加：

```go
func TestUsageQueuePluginOmitsEmptyUpstreamResponseModel(t *testing.T) {
	withEnabledQueue(t, func() {
		(&usageQueuePlugin{}).HandleUsage(context.Background(), coreusage.Record{
			Provider: "openai", Model: "gpt-5.4", ExecutorType: "OpenAIExecutor", AuthType: "apikey",
		})
		payload := popSinglePayload(t)
		requireMissingField(t, payload, "upstream_response_model")
	})
}
```

**步骤 2：运行测试确认失败**

运行：`go test ./internal/redisqueue/ -run 'TestUsageQueuePluginPayloadIncludesStableFieldsAndSuccess|TestUsageQueuePluginOmitsEmptyUpstreamResponseModel' -count=1`

预期：稳定字段测试在 `requireStringField` 处 FAIL（缺键）；省略测试在实现前可能 PASS（缺键），以稳定字段测试的业务断言为有效红。

**步骤 3：写最小实现**

`queuedUsageDetail` 增加：

```go
UpstreamResponseModel string `json:"upstream_response_model,omitempty"`
```

`HandleUsage` 的 `json.Marshal(queuedUsageDetail{...})` 增加：

```go
UpstreamResponseModel: strings.TrimSpace(record.UpstreamResponseModel),
```

**步骤 4：运行测试确认通过**

运行：`go test ./internal/redisqueue/ -count=1`。预期：PASS。`gofmt -w internal/redisqueue/plugin.go internal/redisqueue/plugin_test.go`。`go build -o test-output ./cmd/server && rm test-output`

**步骤 5：提交**

```bash
git add internal/redisqueue/plugin.go internal/redisqueue/plugin_test.go
git commit -m "feat(T05): emit upstream_response_model on usage queue"
```
